Good to know

The web version of sanggup always carries the latest lessons. The Android test build v0.2.1 (in the app gallery) bundles everything up to the deep-link fixes; anything newer on the web waits for the next APK. Progress survives an in-place update: an automated proof installed v0.2.0, recorded progress through the real UI, updated to v0.2.1 in place, and confirmed every done stage, the streak and the pending sign-off request survived. The proof re-runs on each release.
